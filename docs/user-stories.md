# User Stories

## 1. Manage Income and Expenses
As a university student, I want to create an account and record my income and expenses, so that I can manage all my financial records in one place.

## 2. Manage Monthly Budget
As a university student, I want to set a monthly budget and view my expenses, so that I can control my spending and avoid exceeding my budget.

## 3. Track Savings and Analyse Spending Patterns
As a university student, I want to track my savings goals and analyse my spending patterns, so that I can improve my financial planning and make better budgeting decisions.
